Chroma 设计语言

一个受 Material Design 3 与 M3 Expressive 启发的 MediaWiki 皮肤原型

示例条目 最后编辑于今天 5 分钟阅读

Chroma 是一个面向 MediaWiki 的皮肤项目，目标是把 Material Design 3 的色彩、排版、形状与动效系统带入 wiki 的阅读与编辑体验，同时保持 MediaWiki 的既有结构与扩展兼容性。

阅读模式已就绪 点击右上角的书本图标，隐藏侧栏与工具，专注长文阅读。

设计原则

  • 阅读优先：正文安静、工具后退，阅读模式是一等公民。
  • Token 驱动：组件不写死颜色，全部解析到 --md-sys-* 变量。
  • 渐进增强：无 JavaScript 也能阅读、导航与搜索。
  • 零外部请求：字体、图标与脚本随皮肤分发，不依赖 CDN。

色彩系统

所有颜色由 seed color 生成五组 tonal palette，再映射为 MD3 语义角色。下面的表格展示浅色主题中的主要角色：

Token用途浅色值
--md-sys-color-primary主操作、链接#006a6a
--md-sys-color-surface页面底色#f6fbfa
--md-sys-color-surface-container卡片、分区#eaf1f0
--md-sys-color-on-surface正文文字#171d1d
--md-sys-color-outline-variant分隔线#bec9c8
 
/* 站点 CSS 可以直接覆盖 token */
:root {
  --md-sys-color-primary: #005a5a;
}

排版与节奏

正文使用 MD3 body-large 字阶，行高 1.75，中文优先使用系统字体，拉丁字母使用 Roboto Flex 子集。标题层级按 headline / title 划分，避免在 wiki 内出现过多层级。

好的 wiki 皮肤应该让读者忘记皮肤的存在，只在需要时提供熟悉的工具。

布局与切换

默认是应用式布局：顶栏、导航抽屉、正文与右侧目录。偏好设置中可切换为阅读式布局，接近 Vector 2022 的左侧栏结构。两个布局共享同一套模板与 token。

移动端断点下，抽屉变为覆盖层，正文单列，编辑按钮变为浮动操作按钮。
